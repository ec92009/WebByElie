03 // PROCESO

Conservar lo que funciona y mejorar el resto.

Proceso y presupuesto →
  1. 01

    Revisar lo existente

    Una breve entrevista inicial y revisión del sitio actual: qué ya funciona, qué conviene conservar y dónde se atascan los visitantes. Si hay analítica disponible, informa la revisión; si no, la primera pasada sigue siendo observacional y práctica.

  2. 02

    Explorar posibles estilos

    Una pequeña paleta de direcciones reales para comparar páginas concretas en lugar de descripciones abstractas.

  3. 03

    Elegir y combinar

    Elija una dirección o combine piezas de varias opciones, incluido el sitio actual, hasta que encaje bien.

  4. 04

    Preparar el sitio final

    Ajustar páginas, detalles de búsqueda, estructura preparada para IA, flujo móvil y elementos prácticos antes de aprobar.

06 // GASTOS WEB

Dónde se esconden los costes silenciosos.

Detalles de limpieza de costes →

01 // Suscripciones

Aplicaciones del sitio, herramientas de reservas, complementos de correo, analítica, imagen o IA que nadie usa activamente.

02 // Solapamientos

Dos servicios haciendo lo mismo, plugins antiguos conservados por costumbre o un plan de pago que quedó grande.

03 // Renovaciones

Dominios, alojamiento, temas, plugins y directorios que se renuevan solos sin aportar ya al negocio.

04 // Propiedad

Accesos poco claros, facturación dispersa y cuentas de proveedores que ocultan qué es esencial. Los ahorros se tratan como oportunidades para verificar, no como una garantía de retorno del proyecto.

08 // RESPUESTAS

Preguntas frecuentes.

Web By Elie es para negocios independientes que ya tienen un sitio web o herramientas web y quieren una renovación práctica, señales de búsqueda más claras, estructura legible para IA y una revisión del gasto web evitable.

La primera pasada revisa el sitio actual, conserva el trabajo útil, identifica fricciones para visitantes, compara direcciones de diseño y revisa títulos, descripciones, encabezados, redacción de servicios, enlaces, flujo móvil, datos legibles para IA y costes evitables.

Comprueba si una persona o un asistente de IA puede identificar sin adivinar el negocio, sus servicios, clientes previstos, zonas de servicio, factores de precio, pruebas y siguiente paso. Registra datos ausentes o contradictorios y recomienda correcciones concretas, sin prometer aparecer en una respuesta de IA.

No se garantiza ningún posicionamiento, tráfico, cliente potencial ni aparición en respuestas de IA. El trabajo mejora la claridad, rastreabilidad, estructura y calidad de las respuestas para que el sitio sea más fácil de entender.

No por defecto. El proceso empieza preservando lo que funciona y luego propone mejoras prácticas de diseño y estructura antes de preparar la dirección final del sitio.

La mayoría de los proyectos empiezan con un paquete inicial de 10 horas. El trabajo se registra a 100 $/hora con notas de progreso y una revisión manual cuando el paquete alcanza el 50 %.
